What AssetValidator Does

A validation gate between artists and production — same rules in GUI, CLI, DCC, and CI.

Scan & validate any publish format

Point at a folder or drag files into the asset list. Built-in scan supports USD, ABC, FBX, OBJ, VDB, EXR, PNG/JPG/TIFF, TX, and more. Pick ruleset general for mixed pipelines, or default / strict for USD-heavy gates.

500+ Built-in Checks

No empty shell — a full validation library ships in the box and shows up in the in-app Plugins panel: paths and naming, USD stage rules, Alembic/FBX/OBJ/glTF, textures, audio, renderers, DCC pipeline hygiene, and delivery rules. Ruleset studio enables the full pack; general runs 470+ multi-format gates for daily publish work.

DCC + studio integrations

Preflight in Houdini, Maya, Blender, Nuke before export. Hooks for ShotGrid, ftrack, Slack, Telegram, Deadline, and GitHub Actions CI.

Extend with custom plugins (Business+)

The built-in library covers most publish gates — but every studio has its own naming and pipeline quirks. TDs can add Python plugins on top: drop .py files in the plugins folder or use the in-app Custom plugins panel. Reload without recompile.

Integrate in Minutes

Drop AssetValidator into your existing pipeline with minimal changes.

CI + Jenkins

Reusable validation gate with JUnit output and shareable HTML artifacts.

validate-assets --ruleset strict --input ci-assets.txt
validate-assets --notify slack --share-serve

ShotGrid + FTrack Publish Hook

Validate on publish and block bad assets before they enter the pipeline.

validate-shotgrid --published-file-id 12345 --ruleset strict
validate-ftrack --asset-version-id abc --asset-root /assets

Slack + Telegram + Deadline

Notify teams on FAIL and run pre-submit checks on the render farm.

validate-assets --notify telegram --share-serve
validate-deadline --ruleset strict
